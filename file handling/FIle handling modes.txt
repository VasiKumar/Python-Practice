character   Meaning
'r'         open for readig (default)
'w'         open for writing, truncating the file first
'x'         create a new file and open it for writing
'a'         open for writing, appending to the end the file if it exists
'b'         binary mode
't'         text mode (default)
'+'         open a disk file for updating (reading and writing)
'r+'        read and overwrite (pointer at start) - no truncate but replace characters of indexes
'w+'        read and overwrite - truncates everything
'a+'        read and append (pointer at end) no truncate here.
